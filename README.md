\# Smart Contracts for Agreements



\## Project Overview

A blockchain-based agreement management system built using Solidity.



\## Features

\- Agreement between two parties

\- Store a document hash

\- Record approvals from both parties

\- Check agreement status

\- Cancel an agreement before both parties sign



\## Technologies

\- Solidity

\- Ethereum Virtual Machine (EVM)

\- Remix IDE

\- Git and GitHub



\## How to Test

1\. Open Remix IDE.

2\. Compile contracts/Agreement.sol.

3\. Deploy using Remix VM.

4\. Sign using Party A and Party B.

5\. Check the agreement status.



\## Limitation

This is an educational prototype. It does not verify real-world identities or guarantee legal validity.
